# 封面拼贴海报

统计页选择日期范围后，打开 **总结海报 → 封面拼贴**。

- 支持全部游戏，或当前日期范围内时长前 6 / 20 / 60 / 120 个游戏，不受原统计排行榜前 50 名限制。
- 海报标题和底部配文可修改；游戏标题、开发商和期间累计游玩时长可分别隐藏。封面图片自身的文字保留。
- 点击封面或“调整封面取景”后，可拖动、滚轮或滑块缩放（1–3 倍），并支持上一张、下一张、恢复居中、Esc 返回全景。
- 裁切按游戏 ID 保留在当前草稿中，改变数量或排布时保留；关闭窗口或切换模板后重新创建草稿，不修改原封面文件。
- 返回全景并完成绘制后，可通过原生保存对话框导出 **3240 × 4320 PNG**，与预览共用同一画布。
- 海报附加文字统一使用系统字体栈；右下角复用 `appicon-dark.png`，无需额外字体下载或打包字体。
- 缺图显示占位并可重试；空日期范围不可导出。新海报不调用 AI，原 HTML 模板流程保留。

布局参考 Lunar 的统计海报（AGPL-3.0），布局、裁切和绘制分别位于 `posterLayout.ts`、`posterCrop.ts` 和 `posterCanvas.ts`。
